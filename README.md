Entry for the [make.fun bounty "One Word for the Boss"](https://make.fun/bounty/u-swift-badger-44-one-word-for-the-boss-6b48c735) — describe the boss in exactly one word.

## The word

**`Roomba`**

A boss bumps into everything, never stops, goes in circles — and somehow the job still gets done. It scored highest of five candidates against the judging rubric (funny / true / fresh): funnier than "Wi-Fi", truer than "Thermostat", and far fresher than office clichés like "Micromanager" or "Deadline".

## How to run

```sh
node main.ts
```

This writes exactly one word — `Roomba`, nothing else — to `/output/entry.txt` and logs the character count (6).
